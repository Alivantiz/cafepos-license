# Генератор ТС по ссылке на товар

Инструмент собирает готовую товарную спецификацию (ТС) по ссылке на товар:
берёт публичные данные о товаре, применяет ваш шаблон и правила обезличивания
и подставляет ваши личные данные **локально**.

## Главный принцип — граница конфиденциальности

Данные разделены на два потока, которые никогда не встречаются в интернете:

**Публичный поток** (можно обрабатывать ИИ — это и так открыто по ссылке):
- ссылка на товар (публичный URL);
- содержимое карточки: название, вариант, цвет/размер, артикул продавца, цена, фото;
- структура шаблона (расположение полей без реальных значений);
- правила обезличивания.

**Конфиденциальный поток** (НИКОГДА не уходит из вашей машины):
- ваши контакты / ник / данные посредника;
- ваша наценка, закупочные цены, внутренние пометки;
- данные клиентов, адреса, реквизиты.

Всё личное хранится только в `секреты.json` — этот файл в `.gitignore`,
не коммитится и не отправляется ни в какой API. Подстановка личных полей —
последний, чисто локальный шаг конвейера.

## Конвейер

```
[ссылка] → (1) скачать карточку товара          → только публичные данные
                     ↓
           (2) ИИ: собрать тело ТС + обезличить  → видит ТОЛЬКО публичные данные
               + точно определить товар             + шаблон-скелет (без секретов)
                     ↓
           (3) локальная подстановка секретов    → готовая ТС в готовые-тс/
               из секреты.json                      (в сеть не выходит)
```

## Структура папки

- `шаблон.md` — скелет ТС с плейсхолдерами (наполняется из вашего примера).
- `правила-обезличивания.md` — что и как обезличивать.
- `секреты.example.json` — схема личных данных (в репозитории, без реальных значений).
- `секреты.json` — ваши реальные личные данные (в `.gitignore`, только локально).
- `примеры-тс/` — обезличенные образцы ваших ТС для анализа шаблона.
- `готовые-тс/` — сюда складываются готовые ТС.

## Как договорились работать сейчас

Пока — только в чате. Вы присылаете:
1. обезличенный пример ТС (реальные личные поля заменены на `[МОЙ_КОНТАКТ]`,
   `[НАЦЕНКА]` и т.п.) — из него выводим шаблон и правила;
2. ссылку на новый товар — по ней собираем ТС на проверку.

Автоматизацию (скрипт/сайт) добавим позже, когда шаблон и правила устоятся.
